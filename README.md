# n8n Learning Projects

A collection of AI Automation workflows built with **n8n**.

## 📂 Projects

### 1. LinkedIn Job Alert Automation
Automates LinkedIn job scraping, processes job data, stores results in Google Sheets, generates AI summaries with Groq, and sends email notifications.

📁 `workflows/linkedin-job-alert-automation`

---

### 2. Dubai AI Agency Outreach Automation
Discovers AI agencies in Dubai using Apify, filters valid leads, generates personalized outreach emails with Groq, and creates Gmail drafts for manual review.

📁 `workflows/dubai-ai-agencies-outreach-automation`

---

## 🛠️ Tech Stack

- n8n
- Apify
- Groq (Llama 3.3)
- Gmail API
- Google Sheets
- Docker
