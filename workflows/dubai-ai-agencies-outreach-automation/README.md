# n8n Learning Projects

A collection of AI Automation workflows built with n8n.

## Projects

### 📌 LinkedIn Job Alert Automation
Automates LinkedIn job scraping, AI-powered job summarization, Google Sheets storage, and Gmail notifications.

📁 `workflows/linkedin-job-alert-automation`

### 📌 Dubai AI Agency Outreach Automation
Finds AI agencies in Dubai, filters qualified leads, generates personalized outreach emails using Groq, and creates Gmail drafts.

📁 `workflows/dubai-ai-agencies-outreach-automation`

## Tech Stack

- n8n
- Apify
- Groq (Llama 3.3)
- Gmail API
- Google Sheets
- Docker
